# 基于 SpringBoot + Vue  的会员管理系统

会员管理 · 活动预约 · 积分兑换 · 在线缴费 · 投票管理 · 研究任务 · 打卡签到 · 学术交流 · 数据统计

本项目是一套面向协会/学会/商会/社群等组织的会员管理服务平台，采用前后端分离架构，覆盖**管理员、会员**两类角色。系统围绕"会员管理、活动管理、活动预约、积分兑换、在线缴费、研究任务、打卡签到、会议记录、投票管理、资料文档、会员沟通、数据统计"等核心业务设计，支持从会员注册、活动参与、积分累积、在线缴费，到研究任务分配、投票管理、数据统计的全链路数字化运营，构建"会员+活动+积分+缴费+交流"一体化的会员管理平台。

## 核心特性

- **会员全生命周期管理**：支持会员注册、个人信息维护、会员等级管理（基于等级规则自动升降级）、会员缴费与续费、会员状态管理（正常/欠费/冻结/注销），实现会员全生命周期数字化管理。
- **活动管理与预约**：管理员可创建活动（学术会议/培训讲座/会员聚会/户外活动等），设置活动时间、地点、人数上限、费用、积分奖励；会员可浏览活动展板、在线预约报名、查看活动详情与参与记录。
- **积分兑换体系**：基于等级规则配置积分获取方式（签到打卡/参与活动/完成任务/缴费等）与兑换规则，会员可通过积分兑换礼品/服务/活动优惠券，支持兑换记录查询。
- **在线缴费与会员续费**：支持会员在线缴纳会费（年费/季费/月费），支持微信/支付宝支付，缴费记录自动关联会员档案，支持缴费提醒与欠费预警。
- **研究任务与打卡签到**：管理员可发布研究任务，分配给指定会员或小组，设置任务截止时间与积分奖励；会员可查看任务、提交成果、每日打卡签到累积积分，支持打卡记录查询。
- **投票管理**：管理员可发起投票（选举/评选/意见征集等），设置投票规则与截止时间；会员可参与投票、查看投票统计结果，支持匿名投票与实名投票。
- **学术会议与会议记录**：支持学术会议创建、参会人员通知、会议纪要记录与归档，会员可查看参与的会议记录与会议纪要。
- **资料文档共享**：支持文档分类上传、版本管理、权限控制与全文检索，会员可浏览下载资料文件，管理员可管理文档库。
- **会员沟通与留言**：会员可发布留言进行工作沟通或问题反馈，管理员可查看并回复留言；支持会员之间内部消息沟通，形成闭环交流机制。

## 功能模块概览

## 管理员端

管理员为平台最高权限角色，负责全局配置与数据监管：

### 账号与基础

- **管理员管理**：管理管理员账号，包括账号增删改查、角色分配、权限配置、登录日志查看，支持修改密码与安全设置。
- **会员管理**：管理平台会员信息，包括姓名、手机号、会员编号、所属小组、会员等级、入会时间、缴费状态、账户状态，支持会员信息增删改查、会员等级调整、账户冻结/解冻。
- **职位管理**：管理会员职位/角色字典，包括职位名称（会长/副会长/理事/普通会员等）、职位描述、职位权限，支持职位增删改查。
- **等级规则**：配置会员等级规则，包括等级名称（普通会员/银卡会员/金卡会员/钻石会员等）、升级条件（积分阈值/缴费年限/活动参与次数）、等级权益（折扣/积分倍率/专属活动），支持等级规则增删改查。
- **小组管理**：管理会员小组，包括小组名称、小组负责人、小组描述、小组成员列表，支持小组增删改查与成员调整。

### 活动与会议

- **活动管理**：创建活动与管理活动，包括活动名称、活动类型（学术会议/培训/聚会/户外等）、活动时间、活动地点、人数上限、活动费用、积分奖励、活动海报、活动详情，支持活动编辑、取消、已结束活动归档。
- **活动预约**：查看活动预约记录，包括预约会员、预约时间、预约状态、支付状态，支持预约审核、预约取消、预约人数统计。
- **会议记录**：管理学术会议记录，包括会议名称、会议时间、会议地点、参会人员、会议纪要、会议状态，支持会议创建、编辑、删除与纪要归档。

### 任务与打卡

- **研究任务**：发布与管理研究任务，包括任务名称、任务描述、任务截止时间、积分奖励、分配对象（指定会员/指定小组）、任务状态，支持任务进度跟踪与成果审核。
- **打卡记录**：查看会员打卡签到记录，包括打卡会员、打卡日期、打卡时间、打卡地点（可选）、连续打卡天数，支持打卡数据统计与异常打卡处理。

### 积分与缴费

- **会员缴费**：查看会员缴费记录，包括缴费会员、缴费金额、缴费类型（年费/季费/月费）、支付方式、缴费时间、缴费状态，支持缴费审核与缴费提醒。
- **积分兑换**：配置积分兑换商品/服务，包括兑换物品名称、所需积分、库存数量、兑换规则、物品图片，支持兑换物品增删改查。
- **兑换记录**：查看会员积分兑换记录，包括兑换会员、兑换物品、消耗积分、兑换时间、兑换状态（待发货/已发货/已完成），支持兑换订单处理。

### 投票与内容

- **投票管理**：发起与管理投票，包括投票标题、投票描述、投票选项、投票规则（单选/多选/匿名/实名）、截止时间、可见范围，支持投票编辑、提前结束、投票结果查看。
- **投票记录**：查看投票参与记录，包括投票人、投票选项、投票时间，支持投票数据导出与统计分析。
- **公告管理**：发布与管理平台公告，包括公告标题、内容、类型（通知/活动/规则变更）、发布时间、置顶状态、可见范围，支持公告编辑与删除。
- **留言列表**：查看会员留言记录，包括留言内容、留言人、留言时间、处理状态，支持管理员回复与留言删除。
- **消息信息**：管理系统消息推送，包括消息标题、内容、接收对象（全体/指定等级/指定小组/指定会员）、发送状态，支持批量发送系统通知。
- **用户通知**：查看用户通知发送与阅读情况，包括通知标题、接收人、已读/未读状态、发送时间，支持通知记录查询。

### 资源与数据

- **资料文档**：管理共享文档库，包括文档名称、分类、上传者、上传时间、下载次数、可见范围，支持文档审核、违规内容处理、文档分类管理。
- **数据统计**：综合数据看板，展示核心运营指标（会员总数/今日活跃/本月缴费金额/活动参与率/积分兑换次数/投票参与率），支持会员增长趋势、活动参与排行、缴费趋势分析、积分分布统计、投票结果统计等多维度图表展示，支持报表导出。

## 用户端（会员）

会员为平台使用方，可参与活动、累积积分、在线缴费：

### 账号与个人

- **注册登录**：支持手机号+验证码注册登录，首次登录自动创建会员档案，支持找回密码。
- **密码修改**：支持会员自主修改登录密码，保障账户安全。
- **个人信息**：查看与编辑个人基本信息，包括姓名、手机号、邮箱、所属小组、会员等级、入会时间、个人简介，支持头像上传。

### 活动与会议

- **活动展板**：浏览平台活动列表，支持按活动类型/时间/状态筛选，查看活动详情（时间/地点/费用/积分奖励/剩余名额），支持活动收藏。
- **活动预约**：在线预约报名活动，支持选择参与人数、填写备注信息，预约成功后可查看预约状态与活动提醒，支持预约取消。
- **学术会议**：查看本人参与的学术会议记录，包括会议名称、会议时间、会议地点、会议纪要，支持会议纪要下载与回顾。

### 任务与打卡

- **研究任务**：查看分配给自己的研究任务，包括任务名称、任务描述、截止时间、积分奖励、任务状态，支持提交任务成果（文字/文件）、查看任务审核结果。
- **我的打卡**：每日在线打卡签到，查看个人打卡记录、连续打卡天数、打卡积分累积，支持打卡日历查看。

### 积分与缴费

- **会员缴费**：在线缴纳会费，选择缴费类型（年费/季费/月费），查看缴费金额与会员等级权益，支持微信/支付宝支付，支付成功后会员等级自动更新。
- **在线缴费**：缴纳活动费用或其他应缴费用，查看费用明细与支付记录。
- **积分兑换**：浏览可兑换物品列表，查看所需积分与库存，在线提交兑换申请，消耗积分完成兑换，支持查看兑换订单状态。
- **兑换记录**：查看本人全部兑换记录，包括兑换物品、消耗积分、兑换时间、兑换状态，支持兑换订单详情查看。

### 沟通与消息

- **资料文件**：浏览共享文档库，支持按分类搜索文档，查看文档详情与下载，支持文件阅读权限控制。
- **留言发布**：向管理员发布留言，包括留言内容、留言类型（问题反馈/建议意见/求助），支持查看留言回复记录。
- **会员沟通**：与其他会员进行内部消息沟通，支持消息发送与沟通记录查看。
- **请假申请**：向管理员提交请假申请（如无法参与活动/任务延期等），填写请假事由与时间，支持查看审批进度。
- **我的消息**：查看个人收到的所有系统消息，包括活动提醒、任务通知、缴费提醒、投票通知、留言回复等，支持已读/未读管理。

### 投票

- **我的投票**：查看本人参与的投票记录，包括投票标题、投票选项、投票时间，支持查看历史投票。
- **投票统计**：查看已截止投票的统计结果，包括各选项票数分布、参与人数、投票趋势图表。
